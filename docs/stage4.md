# Dashboard

El objetivo es que apenas suba su csv, el usuario pueda ver estadisticas, empezar a ver los calculos de sus consumos

Algo muy importante, el .csv puede traer diferentes fechas, cursor exporta por dia, semana, mes, MTD y mes pasado, asi que el dashboard debe ser capaz de manejar diferentes fechas y mostrar las metricas en base a ellas.

Quiero un dashboard con diferentes metricas y estadisticas en base a ese .csv con graficos, con un aspecto financiero, como los graficos de barras (Proponme las metricas que se pueden generar en base a los datos del csv, y que sean relevantes para el usuario)

Sin informacion desorganizada, enfocado en llamar la atencion del usuario

Antes de programar usa /vercel-react-best-practices, para un codigo pulido y pasar las pruebas de react doctor
