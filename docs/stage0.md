# Stage 0 - Setup

La idea es que este stage, se dedique unicamente a la configuracion de dependencias, carpetas, archivos y entorno de desarrollo

El siguiente stack es el que se va a usar en el proyecto:

- Framework: Next.js 16 (última versión estable, pineada)
- Routing: App Router (/app)
- Styling: Tailwind CSS + Shadcn UI
- Bundler: default de Next (NO Vite)
- Deployment target: Vercel
- TypeScript: sí
- Estructura simple, sin overengineering
- Bun como entorno de ejecucion para el desarrollo

Output esperado: proyecto base limpio con el stack configurado
